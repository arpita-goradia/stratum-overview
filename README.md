# Stratum.AI

An end-to-end RAG-based verification platform that validates financial figures, academic citations, and factual claims against authoritative sources — including SEC EDGAR and CrossRef — before they reach users.

**Note:** This repo contains a project overview only. Source code is private.

## Tech Stack
FastAPI · AWS EC2 · Docker · ChromaDB · RAG architecture · Semantic embeddings

## What it does
- Validates financial figures against SEC EDGAR filings
- Cross-checks academic citations via CrossRef
- Applies confidence scoring and evidence-backed corrections
- Ships as a Chrome extension for real-time verification
